# PFE Report Writing Style

This guide defines a consistent technical and academic writing style for an end-of-study project report.

## General principles

- Use a technical and academic style that remains connected to the completed project.
- Start every section with clear context before presenting technical details.
- Guide the reader through a sequence of context, observation, method, illustration, result, and interpretation.
- Prefer paragraphs when they communicate an idea more clearly than a long list.
- Keep meaningful headings while avoiding excessive internal subheadings.
- Use short to medium length paragraphs that are dense enough to be useful and easy to read.
- Use “we” to describe the approach, decisions, and work completed by the project team.
- Relate theory to the implemented solution so the report does not read like a general course.

## Figures, tables, and examples

- Introduce each figure or table before it appears.
- Explain what a figure or table shows and why it is useful immediately afterwards.
- Use figures to support an argument, not only for decoration.
- Accompany technical examples with an interpretation of their meaning and result.

## Chapter style

- Begin each chapter by placing its subject in the project context.
- Move gradually from general concepts to their application in the solution.
- End important sections with a transition sentence that prepares the next topic.
- Avoid a sequence of isolated definitions.
- Aim for a smooth project report narrative instead of a course handout.

## Reference formula

The intended style combines academic structure, technical narrative, explicit transitions, restrained headings, justified examples, and a constant connection to the implemented solution.
